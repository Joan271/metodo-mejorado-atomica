# Física Atómica: Método optimizado de obtención de términos L-S y j-j para electrones degenerados
Este trabajo enmarcado en la Física Atómica y Molecular, consiste en mejorar la eficiencia en la metodología de obtención de términos espectrales L-S o j-j mediante la introducción de herramientas como la combinatoria. La principal motivación es la idea de reducir la fuente de error humano en la búsqueda de los términos mediante un método sistemático y fácilmente generalizable.
 El documento está escrito en LaTeX y puede compilarse directamente a partir de los archivos fuente incluidos en este repositorio.
